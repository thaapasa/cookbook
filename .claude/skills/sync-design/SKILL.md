# Design sync

Read `design/CLAUDE.md` first. It names the canvas, lists which files to copy,
and gives the sync steps. Follow those steps to update `design/` to match the
canvas.

When the sync is done, tell the user which boards were added, changed or
removed. If the canvas version had not changed, say so and stop.
