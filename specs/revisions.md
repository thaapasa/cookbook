# Revisions

Every save of a recipe creates a revision, so any change can be viewed and
undone. This covers changes from the editor and from Claude.

- [ ] Each revision records the author (a family member or Claude) and an
      optional note on what changed.
- [ ] User can view the revision history of a recipe.
- [ ] User can restore an earlier revision.
- [ ] Adding, editing or removing a note does not create a revision.
