# Recipe list

The front page. Shows the recipes that match the current search and filters.

- [x] User can search recipes with full-text search.
- [x] User can filter recipes by tags.
- [x] The page shows all matching recipes at once, without pages. The photos
      load as they scroll into view.
- [x] Once the page is scrolled down, a floating button scrolls back to the
      top.
- [x] Search matches the title, tags, description, ingredients and steps.
- [x] Search matches parts of compound words, such as "keitto" in "kanakeitto".
