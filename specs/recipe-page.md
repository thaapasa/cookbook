# Recipe page

Shows a single recipe.

- [ ] The page shows the recipe photo, ingredients and steps.
- [x] The page shows the recipe tags.
- [x] User can open the cooking view from the page.
- [x] The ingredients show the amount, name and note in separate columns. The
      note is less prominent than the name.
- [x] Ingredient groups are shown under their names.
- [x] The page shows the servings and the active and total time when they are
      set.
- [x] The description is shown above the ingredients when it is set.
- [x] The page shows the notes of the recipe with their authors and dates,
      newest first.
- [x] User can add a note from the page.
- [x] User can open the editor from the page.
- [x] User can delete the recipe after confirming. Deleting removes the photo,
      notes and revision history.
- [x] Step groups are shown under their names.
- [x] The source is shown as a link when it is a URL, otherwise as text.
