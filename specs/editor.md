# Editor

Editing recipes in the browser.

- [ ] User can create a new recipe.
- [ ] User can edit all fields of a recipe.
- [ ] User can upload a photo for a recipe.
- [ ] User can add and remove tags.
- [ ] User can edit ingredients as rows with amount, name and note fields.
- [ ] User can add, remove, rename and reorder ingredient groups.
- [ ] User can move between ingredient fields with the keyboard and add a new
      row from the last field.
- [ ] User can reorder ingredients by dragging, also between groups.
- [ ] User can edit steps as a list of text fields, and add, remove and reorder
      them by dragging, also between groups.
- [ ] User can add, remove, rename and reorder step groups.
- [ ] User can edit and remove the notes of a recipe.
