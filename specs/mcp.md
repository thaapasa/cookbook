# MCP server

Lets Claude manage recipes. Claude imports recipes from web pages, photos and
text, adjusts existing recipes on request, and builds weekly shopping lists from
the ingredients of planned dishes.

- [ ] Callers authenticate with a bearer token.
- [ ] Claude can search and list recipes.
- [ ] Claude can read a recipe.
- [ ] Claude can create a recipe.
- [ ] Claude can edit a recipe, with a note on what changed.
- [ ] Claude can upload a photo for a recipe.
- [ ] Claude can get the ingredients of several recipes in one call.
- [ ] Claude can list the existing ingredient names, to keep names consistent
      across recipes.
